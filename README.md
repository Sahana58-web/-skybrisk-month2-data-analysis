   # Skybrisk Month 2 - Data Analysis with Pandas

   Sales data analysis project for the Skybrisk internship (Month 2: Data Analysis with Pandas).

   ## Files
   - analysis.py - main analysis script
   - sales_data.csv - sample sales dataset
   - sales_by_category.png - chart of total sales by category
   - sales_by_region.png - chart of total sales by region
   - summary_report.txt - written summary of insights

   ## How to run
   pip install pandas matplotlib seaborn
   python analysis.py
